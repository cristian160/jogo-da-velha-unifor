## 🚀 Instruções de Execução (Local)
Caso deseje rodar a aplicação localmente em sua máquina, siga os passos abaixo:
1. Faça o clone deste repositório: `git clone https://github.com/cristian160/jogo-da-velha-unifor.git`
2. Navegue até a pasta do projeto.
3. Abra a pasta `src`.
4. Dê um duplo clique no arquivo `index.html` para abri-lo em qualquer navegador web moderno (Chrome, Edge, Firefox, etc.).
5. Nenhuma instalação de dependência ou servidor local é necessária.
